# P6-603 — UX Acceptance Checklist

- [ ] Authenticated user can open and leave the Workflow Builder.
- [ ] Node Library supports click-to-add and drag-and-drop.
- [ ] Nodes can be moved by pointer and by keyboard arrow keys (Shift + arrow for larger steps) without moving the viewport.
- [ ] Output-to-input connection works and displays a directional edge.
- [ ] Condition branches display distinct Yes/No labels.
- [ ] Invalid self, duplicate, occupied-input, and cyclic connections are rejected with feedback.
- [ ] Node/edge selection and property editing work.
- [ ] Node/edge deletion removes dependent graph references.
- [ ] Zoom controls work and canvas scrolling remains usable.
- [ ] Thai text, narrow viewport, dark mode, and reduced motion are reviewed.
- [ ] Prototype-only / no-backend / no-Windows-action boundaries are visible.
- [ ] Existing chat and authentication regressions are checked.
- [ ] Build, unit, and browser E2E results are recorded against the exact commit.
- [ ] Performance claims are omitted unless measured with reproducible fixtures and environment.
