# P5-515 — QA Matrix to Test Traceability

## Scope and method

This is a source-level traceability review of the test files present on `main` when this document was prepared. It maps each matrix requirement Q01–Q35 to exact test function names or frontend test descriptions. A mapping means a test exists; it does **not** independently claim a fresh test run. The latest CI evidence remains the successful GitHub Actions runs recorded in [P5-515 Verification Evidence](P5-515-VERIFICATION-EVIDENCE.md).

Status meanings:

- **Covered** — an existing test directly asserts the principal expected behavior.
- **Partial** — related assertions exist, but one or more parts of the matrix scenario are not directly exercised.
- **Not covered** — no direct test was found for the stated scenario.
- **Not evidenced** — static implementation or a test comment alone is not accepted as test coverage.

All mapped tests use synthetic inputs, in-process clients, mocks, or fake data. This review does not add or authorize live machine operations.
